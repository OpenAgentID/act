# Support

| You need | Go to |
|---|---|
| How-to questions | The [OpenAgentID docs](https://docs.openagent.id) |
| A bug or a feature request | [Open an issue](https://github.com/OpenAgentID/act/issues/new/choose) |
| A security issue | [SECURITY.md](SECURITY.md): report privately, never in a public issue |

Maintainers triage new issues within 3 business days.
